---

## ✨ 核心特色
- 🚄 **全台 900 班列車、215 個車站完整收錄**：涵蓋西部幹線、東部幹線、南迴線及四大支線（平溪/深澳、內灣/六家、集集、沙崙）。
- 🔀 **全路網動態圖搜尋（無限次轉乘）**：自動規劃跨主幹線、支線之 1~4 次多段接駁（如平溪 ➔ 內灣、車埕 ➔ 台北、沙崙 ➔ 內灣）。
- ⚡ **即時自動刷新（Live Auto-Refresh）**：輸入或切換站名、時間、條件時，0.2 秒內全自動重新運算。
- 📱 **100% 離線可用 & 支援手機 PWA**：無後端、無外部 API 依賴，即使火車進入山洞或無網路狀態下依然秒查。
- 📊 **多階自訂排序**：支援主次雙階複合排序（如：抵達時間最早 + 行駛時間最短）。
